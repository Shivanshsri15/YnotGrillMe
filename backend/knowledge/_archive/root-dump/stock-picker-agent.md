# Stock Picker Agent — multi-agent financial research workflow

## Summary

The project is described as a CrewAI-based workflow that researches trending companies and helps select stocks based on gathered financial/research context. It is a research and decision-support project, not evidence of investment performance.

## Technologies recorded in project notes

- CrewAI
- OpenAI API
- LangChain
- SerperDev search
- Pushover notifications
- SQLite-backed memory
- ChromaDB / embeddings

## Safe positioning

Describe this as an experimental multi-agent research workflow. Do not claim that it reliably predicts stock prices, produces profitable trades, or provides personalized financial advice. No audited performance data or investment backtest is present in the available materials.
