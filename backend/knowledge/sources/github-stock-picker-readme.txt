The README describes Stock Picker Agent as a CrewAI multi-agent financial research workflow. A manager coordinates three specialist agents: trending-company finder, financial researcher, and stock picker. The project uses GPT-4/GPT-4o-mini, SerperDev web search, Pushover notifications, SQLite long-term memory, ChromaDB, and OpenAI embeddings (`text-embedding-3-small`). The README says long-term memory is active, while short-term RAG memory and entity memory are commented. It lists output artifacts `trending_companies.json`, `research_report.json`, and `decision.md`. The README's aspirational descriptions of investment recommendations are not evidence of profitable trading, validated predictive accuracy, or financial advice quality.
