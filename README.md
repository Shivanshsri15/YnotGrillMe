# Why Not Grill Me?

Interactive AI-powered engineering portfolio — grill-themed, graph-navigated.

```text
YnotGrillMe/
  backend/    NestJS API + Markdown knowledge
  frontend/   Vite + React (butcher-paper × data-structures UI)
```

## Theme (frontend)

**Premium charcoal grill (product UI)**

- Full-bleed coal stage + perspective grate + restrained ember heat  
- Brand-first hero → interactive doneness → session preview → projects → leave-with  
- Display: Unbounded · Body: Outfit · Mono: IBM Plex Mono  


## Quick start

### Backend

```bash
cd backend
cp .env.example .env   # if needed
npm install
npm run start:dev
```

API: http://localhost:3000/api/v1/health  

Docs: [backend/README.md](backend/README.md)

### Frontend

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

App: http://localhost:5173
